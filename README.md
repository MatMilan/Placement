# Схема размещения

Рассадка участников по залу и печать схемы на A4 (книжная ориентация).
Без сборки, без зависимостей, без сервера. Данные не покидают браузер.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий, например `placement`.
2. **Add file → Upload files** — перетащите содержимое этой папки целиком, сохраняя структуру.
3. **Settings → Pages**: Source — *Deploy from a branch*, Branch — `main`, папка — `/ (root)`. Save.
4. Через минуту появится ссылка `https://ваш-логин.github.io/placement/`.

Обновление: правите файл на GitHub → Commit → сайт пересобирается за 30–60 секунд.
Файл `.nojekyll` отключает обработку Jekyll, чтобы файлы отдавались как есть.

## Запуск с диска (двойной щелчок по index.html)

Браузер запрещает странице читать соседние файлы, поэтому при первом открытии
приложение попросит **указать папку проекта**. Выберите папку, где лежат `index.html`
и подпапка `templates`. Файлы никуда не отправляются — они читаются локально.

Выбор запоминается: при следующих запусках шаблоны берутся из памяти браузера.
Если вы поправили `templates/halls.json`, нажмите **«Обновить из папки»** над схемой.

## Формат шаблона

Координаты — миллиметры от левого верхнего угла листа A4 (210 × 297).

- `room` — прямоугольник стен; `doors`, `windows` — участки стен (`side`, `a`, `b`).
- `furniture` — объекты: `shape` = `rect` / `round` / `capsule` / `ellipse` / `ring`.
  У `ring` (стол буквой «О») поле `t` — толщина столешницы, `r` — скругление углов;
  середина остаётся свободной, проверка наложений учитывает только четыре полосы периметра.
  Подпись объекта ставится по центру, либо в точке `labelAt: [x, y]`.
- `seats` — места: `chair` = `[x, y, w, h]`, `font` = `main` / `side`, `zone` — куда класть подпись.
- `seatRows` — регулярные ряды: `cols` (центры колонок), `rows` (`y0`, `step`, `count`), `idFrom`.
  Разворачиваются в обычные места при загрузке.
- Расстановка может наследовать другую: `"from": "sov_base"` плюс `keepBlocks`, `hideBlocks`,
  `keepSeats`, `hideSeats`, `keepFurniture`, `hideFurniture`, `addFurniture`.
  Идентификаторы мест сохраняются — рассадка не теряется при переключении режима.
- `"hidden": true` — служебная базовая расстановка: доступна для наследования, но не показывается в списке.

Зоны подписей: `band` (колонка слева/справа), `below`, `above`, `left`, `right`.

### Студия ВКС

Зал с тамбуром в левом верхнем углу (вход на левой стене). Стол П-образный, раскрыт вверх:
две боковины и нижняя перекладина. По три стула справа и слева от стола, у нижнего торца —
одно председательское место (`s01`) либо два (`s02`, `s03`), два стула у левой стены и один
у правой. Все подписи основного размера. Нумерация: `s01` — председательское,
`s02`–`s03` — председательская пара, `s04`–`s06` — левая сторона стола, `s07`–`s09` — правая,
`s10`–`s11` — левая стена, `s12` — правая стена. Подробности — в `docs/vks-furniture.md`.

### Совещательный зал

Стол буквой «О»: `t = 15` (торцы), `tx = 30` (боковины). При ширине стола 57.2 мм боковины
30 + 30 мм закрывают отверстие, поэтому стол отображается сплошным; чтобы вернуть отверстие,
увеличьте `w` больше 60 мм. Окна: справа четыре, слева два (91.64–140.11 и 160.89–209.36).
Подробности — в `docs/sov-furniture.md`.

Нумерация мест единая для всех пяти расстановок: `s01` — председательское,
`s02`–`s11` — левая сторона стола, `s12`–`s21` — правая, `s22`–`s23` — верхний торец,
`s24`–`s25` — правая стена, `s26`–`s35` — левая стена, `s36`–`s37` — второй председательский состав.
Расстановки только скрывают места, номера не перенумеровываются.

## Горячие клавиши

`Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y` — отмена и повтор · `Ctrl+A` — выделить всех ·
`Del` — снять с места · `Esc` — сбросить выбор · `Ctrl+F` — поиск · `Ctrl+S` — проект ·
`Ctrl+P` — печать · `+` `−` `0` — масштаб.

## Данные

Список участников и рассадка хранятся в `localStorage` браузера пользователя.
На GitHub лежит только код и геометрия залов — никаких персональных данных.
Номера мест никогда не перенумеровываются автоматически: при открытии старого проекта
несовпавшие привязки снимаются с явным сообщением, остальные остаются на своих местах.
Номера мест видны на экране и не попадают ни в PDF, ни в печать.
