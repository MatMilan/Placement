Вы открыли приложение прямо с диска. Браузер не разрешает ему самому читать соседние файлы — поэтому папку нужно выбрать один раз вручную.

templates/halls.jsondemo/demo-list.csv

Браузер спросит «загрузить файлы» — это стандартная формулировка выбора папки. Ничего никуда не отправляется: файлы читаются и остаются в вашем браузере. Выбор запоминается, повторно спрашивать не будем.

Совет: по ссылке на GitHub всё это не нужно — там приложение открывается сразу.
